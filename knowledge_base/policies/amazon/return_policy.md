# Amazon Return Policy

Amazon return eligibility commonly depends on product category, seller terms, delivery date, condition of the item, and the stated return window. Consumers should preserve the order invoice, return request record, product photographs, pickup records, and support chat or email history.

For wrong, damaged, defective, or materially different products, consumers should report the issue promptly through the order support flow and request a refund, replacement, or escalation. If a return or refund is denied, the consumer should ask for the exact reason in writing and compare it with the stated return terms.
